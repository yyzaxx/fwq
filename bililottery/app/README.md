# BiliLottery Web 绿色发布版 v1.0.0

适用于 Windows 10/11 x64。已包含 Node.js v24.18.1、Web 应用完整源码、LotteryAutoScript v2.11.3 引擎和全部生产依赖，无需另装 Node.js 或运行 npm install。

## 直接运行

1. 将整个压缩包解压到新文件夹，请勿直接在压缩软件内运行。
2. 双击根目录的 `启动Web版.cmd`。服务就绪后自动打开浏览器。
3. 默认地址为 http://127.0.0.1:8787 。如果端口已被占用，启动器会自动选择后续空闲端口，以命令窗口显示的地址为准。
4. 运行期间保留命令窗口；按 Ctrl+C 停止服务。关闭浏览器页面不会停止后台任务。

## 首次使用

此发布包不含任何人的 Cookie、账号配置、日志或参与记录，初次运行是全新账号状态和模拟模式。

在“账号与引擎”填写自己的 B 站 UID，保存后扫码登录。在“每日汇总”启用汇总作为唯一来源，并使用汇总 UP UID `492426375`。保存后读取汇总预览；确认任务后再自行切换真实互动模式。

该模式仅使用指定 UP 的互动抽奖、预约抽奖汇总，逐条读取参数并执行，取消启动前整批动态校验。支持 PNG 登录二维码、实时日志、停止任务，以及启动时清理开奖已超过 24 小时且有准确转发记录的本账号动态。

账号和运行记录保存在 `web-data/`，不要分享该目录。同一账号的桌面版和 Web 版请择一运行，避免独立参与记录造成重复互动。

## 源码与许可

- `web/`：Web HTTP 服务和浏览器适配器。
- `src/`：界面、配置、汇总处理、执行与清理逻辑。
- `engine/LotteryAutoScript/`：完整引擎及生产依赖。
- `node/`：自带 Node.js 运行时和对应许可证。
- `test/`：离线回归测试及必要的公开数据样例。
- `SOURCE-INFO.json`、`RELEASE-INFO.json`：来源提交、版本和发布信息。

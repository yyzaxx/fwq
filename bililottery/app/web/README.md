# 本机 Web 版

在项目目录运行 `npm run web`，或双击根目录的“启动Web版.cmd”，浏览器打开 http://127.0.0.1:8787 。需已安装 Node.js，外置引擎依赖安装方式与桌面版相同。

Web 版复用桌面界面和引擎，支持扫码登录、汇总预览、逐条参与、任务停止、实时日志、开奖24小时后的转发清理，也支持手动批量删除动态和近七天中奖通知统计。服务只监听本机地址；公网部署需要认证反代，参见上级目录部署说明。关闭浏览器后任务继续，停止 Node 服务会结束任务。

首次运行将绿色版的账号配置和运行记录复制到独立的 `web-data` 目录。此后分别保存，不自动同步；同一账号请择一运行桌面版或 Web 版，避免重复参与。账号 Cookie 只在本机服务端使用，页面不接收原始凭证。

“账号与引擎”页可输入本机源码路径并点击“连接源码”。目录按钮显示服务端的本机路径。更换端口可在启动前设置环境变量 `BILI_WEB_PORT`。

主页“一键删除动态”默认保留原创，可在“动态清理”面板选择范围。读取后会显示本次清单，确认后才执行；支持停止，模拟模式不会真实删除，保留ID仍生效。手动清理可能包含尚未开奖的转发，删除无法撤销。预览15分钟过期、切换账号或执行模式后须重新读取；服务重启不会续删。

“最近七天中奖次数为”按最近168小时可读取的中奖通知去重，包含已读消息，不会标记已读。登录后空闲时自动更新，或点击“更新统计”。统计不完整时显示未知或旧结果，不能据此认定没有中奖；该数字不涵盖没有收到通知的中奖活动。

# 标题生成规范

## 输入与离线范围

使用刚完成的联合报告或用户指定的已有报告，复用当前对话仍适用的两套模板与字符范围。仅要求改标题时不重新联网、不扩展词库、不另建报告；只有用户要求同步报告时才修改原文件。缺少模板时只询问模板，不自行套用示例。

## 建立当次商品词库

允许占位词源仅有两类：报告中的 Sif 原始流量词、已核实竞品完整原标题。内部建立“占位词 → 具体 Sif 原词或竞品 ASIN/完整原标题位置”的映射。不能确认核实状态或完整性的标题不作为已核实词源。

可以拆取、重排、组合已有词，调整大小写、空格与标点；不能自行增加同义词、派生词或按常识补词。组合短语不因此成为 Sif 已验证的完整搜索词。图片、报告中文说明、旧商品报告、技能示例不提供额外英文词源。

例如 `Neutral` 只有在当次两类合格来源中出现且贴合商品时，才可填入占位；`Framed` 即使出现在竞品标题里，也不能据此认定本商品装框。用户提出增加占位词仍需核对来源，不自动解释成放宽词源限制；缺乏来源时指出并删除，或以相关且有来源的词替换。

固定文字按用户模板保留，不受占位词库限制；报告没提及固定参数不等于冲突。若固定文字与已知实物明确冲突，指出具体矛盾并确认修正，确认前不交付含错误属性的标题。

## 填充模板

保留两套模板的固定文字、顺序和标点，只填写占位。通常三处占位从上到下依次为“主体搭配风格”“画风或背景”“补充氛围、色调或图案”；用户明确修改结构或占位含义时按其新要求执行，不把一次品牌、尺寸作为跨商品默认模板。

每个词除了来源合格，还必须相关、符合商品事实及占位语义。不能借用竞品品牌、尺寸、材质、装框、专属角色或无关图案。词库不足以自然完成模板或达到字符下限时，说明具体缺口并询问必要调整，不堆词、不编词。

## 代码校验

默认标题一 65–75 字符、标题二 115–125 字符，含上下限及空格、数字、标点；用户指定范围优先。每次修改后用代码计算最终字符串，再核对固定文字与占位来源。不要目测、截断单词、暗改固定参数或为了字符数重复堆词。

可将两条最终字符串放入变量后用 Python 校验；以下函数不提供标题模板或额外词源：

```python
def check_titles(title_one, title_two, ranges=((65, 75), (115, 125))):
    for index, (title, (lower, upper)) in enumerate(
        zip((title_one, title_two), ranges), start=1
    ):
        assert "\n" not in title and "\r" not in title, f"标题{index}含换行"
        length = len(title)
        assert lower <= length <= upper, (index, length, lower, upper)
        print(index, length)
```

长度合格不代替词源、事实、语义及模板核验。计数只用于内部校验，默认不在最终答复附字符统计。

## 三块交付

依次输出“标题一：”“标题二：”“N个流量词：”，每项下使用一个单行 `text` 代码块。前两项为实际英文标题，第三项逐字复制报告全部 Sif 原词，按报告顺序用英文逗号加空格 `, ` 分隔，数量与报告一致。

原词复制块不混入竞品标题词、自创组合、中文或数字，不因为标题用过而去重，不扩展为后台 Search Terms。不能为了凑 15 词附上待验证拓展词。

报告仅缺 Sif 词，而竞品词库足以生成两条准确标题时，仍交付两条标题，第三处写“报告未提供流量词”。不能准确生成两条标题时只说明具体缺口及需要调整的范围或词源，不把超出字符范围、无来源或事实冲突的候选列进最终标题交付区。

完整流程在唯一联合报告末尾归档同样的两条标题，各一个单行 `text` 代码块；聊天与报告必须一致，不再复制第二份 Sif 词表。仅据已有报告改标题默认只在聊天交付。默认不增加字符统计、额外建议、五点描述或产品描述。

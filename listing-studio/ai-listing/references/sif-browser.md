# Sif 浏览器注意事项

本文件说明 Sif 调研约束。先读取[现有浏览器操作](browser.md)，不假定当前网站的按钮名称、选择器或页面布局。

## 启动与接管

- 通过当前 CDP 地址连接现有浏览器，Amazon 与 Sif 共用现有会话，不另开独立用户目录或清除登录状态。按实测页面定位控件，不硬编码未经查看的 Sif 布局。
- 连接失败时记录实际错误，不因网页入口能打开就宣称自动化连接或 Sif 查询成功。
- 遇到登录、验证码或授权，停止该页面的自动操作，把当前页面与现有可视浏览器入口交给用户接管，不绕过。等待用户明确完成后再重新读取页面；受阻时继续处理独立的已核实资料，不把查询标成成功。
- 不购买、不联系卖家、不修改 Sif 词库或账户设置，不把账户名称、会员到期、凭据和无关个人信息写进报告或交付内容。

## 查询与证据

确认实际站点、数据周期、周/月口径和查询模式，用户指定优先，默认 US。记录每个真实查询种子及可追溯的查询链接、返回结果位置、查询日期；需要时留存与词条对应的结果证据，避免记录无关账户信息。

读取字段标签和可见数值，不从排名、图表、隐藏字段或权限提示推导搜索量。搜索量缺失、权限受限、未展示都保留真实状态；不能写成 0。ABA 排名单独标注，不能当搜索量；隐藏转化率不能用于选词。

流量词必须是 Sif 实际返回的原词。种子本身、搜索建议、自己拼接的短语、竞品标题中的词，不因被查询或看起来相关就算已验证流量词。保持原文，筛选时按主技能的主题/风格/人群/场景/礼品用途限定及商品相关性要求执行，不足目标数时报告实际数量。

报告需能从每个入选原词追溯到实际查询、周期、模式、来源位置和数值状态。不同日期或周期的结果不能冒充同次查询；复用数据保留原核对日期。

## 收尾

保存唯一联合报告、核对图片及来源、确认实际完成范围后交付；断开自己的 CDP 连接，保留浏览器会话和用户当前页面，不关闭浏览器、不退出账号。仍停在登录、验证码、授权或用户接管时，明确写出未完成部分。此流程不调用 `finish()`。
